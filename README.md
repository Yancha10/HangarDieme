# Hangar Dième

Visionneuse architecturale en français : modèle 3D, plan, coupes et photographies du bâtiment existant. Application publique pour mobile et ordinateur, sans inscription.

Dimensions générales fournies : 24 × 18 m, hauteur latérale de 4 m et point haut de 5 m. Les dimensions secondaires restent estimées à partir des photographies.
